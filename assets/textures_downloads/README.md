# Скачанные текстуры для обзора

Текстуры загружены для ознакомления. Просмотрите содержимое архивов и оставьте только нужные.

## Архивы (распакуйте `unzip имя.zip`)

| Файл | Описание | Лицензия |
|------|----------|----------|
| **kenney_retro-textures-1.zip** | 115 текстур: трава, земля, камень, вода, дороги (ретро-стиль) | CC0 |
| **kenney_development-essentials.zip** | 15 текстур для прототипирования: сетки, placeholder | CC0 |
| **kenney_isometric-roads-water.zip** | 40 тайлов: изометрические дороги, вода, ландшафт | CC0 |
| **kenney_road-textures.zip** | 90 текстур дорог, 64×64 px | CC0 |
| **kenney_prototype-textures.zip** | 75 текстур: сетки, placeholder для разработки | CC0 |
| **kenney_nature-kit.zip** | 330 3D-ассетов: деревья, камни, растения (модели + текстуры) | CC0 |
| **opengameart_wests_textures.zip** | ~50 текстур: трава, земля, камень, мощение, песок, снег, стены (480×480 px) | CC0 |

## Источники

- **Kenney.nl** — kenney.nl/assets
- **OpenGameArt.org** — opengameart.org/content/wall-grass-rock-stone-wood-and-dirt-480

## Как использовать

1. Распакуйте нужные архивы: `unzip kenney_retro-textures-1.zip`
2. Просмотрите PNG-файлы
3. Скопируйте выбранные текстуры в `assets/textures/` (создайте папку)
4. Удалите ненужные архивы и папки
