# Управление кампанией через карту

После входа открывается главное меню «Продолжить / Новая игра». Новая расширенная кампания начинается с Османа; прежние сценарии остаются в выборе новой игры. Сохранения автоматически не переводятся в другие правила.

В кампании карта занимает весь экран. Нажмите город или знамя армии для контекстного окна; закройте его для возврата к прежнему месту. «Правление» открывает совет, войско, государство и летопись. «Неделя» продолжает время до семи дней, «Ждать» предлагает другие сроки. Никакого скрытого включения карты в обучении больше нет.

Крепость: сведения, набор, карточки построек, закупки и назначения. Армия: маршрут, проверка/подтверждение поручения, снабжение, отзыв и единая ведомость сбора похода. Ведомость позволяет собрать существующие армии и подготовить отряды из разных гарнизонов; удалённое формирование происходит после доставки приказа. Чужой город: контакт и дипломатические соглашения по действующим правилам.

Камера, качество и выбранное место запоминаются на устройстве. Правила, люди, войска и приказы исполняются сервером. Поворот, приближение и переключение качества не двигают календарь. Подробности архитектуры, ограничений и месячного тестирования: [telegram-strategy-test.md](telegram-strategy-test.md).
