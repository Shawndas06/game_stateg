## Проверки

- `pytest -q`: API, владение сохранениями, отказ поддельным и просроченным токенам, обе смены правителя, границы доступности наследника, все новые ответы, прежние игровые системы.
- `tests/browser_auth.py`: Chromium/WebKit, Telegram HMAC с тестовым ключом, отклонённые cookie, отказ входа → повтор, потеря ответа создания → восстановление, command401 → один повтор с тем же ID, перезагрузка.
- `tests/browser_ruler_ux.py`: реальные решения и ход времени, обучение/пропуск/повтор, пустые и граничные поля, найм и торговля; Chromium 320/390/1280 и WebKit390.
- `tests/browser_atlas_performance.py`: обе карты, поиск, выбор крепости, масштаб, перетаскивание. В локальном Chromium390 с CPU×4 после изменения открытие 424 мс, четыре перетаскивания 2209 мс против прежнего образца 2425/14128 мс. Это лабораторные замеры, не обещание FPS на Honor. WebKit p95 кадра около 61–62 мс: пространство для дальнейшего ускорения остаётся.
- Локально: 225 Python-проверок прошли, один PostgreSQL-тест оставлен CI. Четыре браузерных контекста проверили также новый экран Мурада.
- `tests/dynasty_scenarios.py`: завершён путь из 3970 распоряжений до дня 27006 под Мурадом, проверены 10 ответов четырёх сцен; фиксированный seed11, законный путь с 1299 года до Мурада; альтернативы разыгрываются из действительно достигнутых состояний. Артефакт `/tmp/dynasty-acceptance.json` включает последовательность действий.
- Полные прежние сценарии, Docker и PostgreSQL проверяются CI. Итоговый статус следует смотреть у текущего SHA, а не у прежнего main.

Осталось: повтор с друзьями на реальном Honor/Telegram, оценка понятности без устных объяснений и измерение одновременных игроков. Эти проверки нельзя заменить локальным браузером. Новое окружение Мурада — начало третьего правления, не вся история до 1389/1453 и не полноценная междоусобица.

## Историческая основа

[Мурад I, TDV](https://islamansiklopedisi.org.tr/murad-i): рождение 1326, правление 1362–1389. В игре появляется взрослым с 1342; это сценарная граница, не утверждение о точной дате вступления в службу. Дата смены власти зависит от партии.

[Лала Шахин, TDV](https://islamansiklopedisi.org.tr/lala-sahin-pasa) — наставник Мурада и военачальник; [Чандарлы Кара Халил, TDV](https://islamansiklopedisi.org.tr/candarli-kara-halil-hayreddin-pasa) — деятель раннего османского управления. Их годы рождения и численные способности приблизительны. Реплики, обучение, денежные обязательства и добровольное отречение — авторские игровые ситуации, не исторические цитаты. Прибытие персонажей не создаёт бесплатных армий.

## Публикация

Настройки GitHub подтверждены: автослияние включено, main требует simulation/mobile-build/container-build, включая администраторов. В панели Render сохранён и повторно прочитан режим After CI Checks Pass.

Цепочка: PR → обязательные simulation/mobile-build/container-build → автоматическое слияние → проверки нового main → Render. Blueprint содержит `branch: main` и `autoDeployTrigger: checksPass` ([документация Render](https://render.com/docs/deploys)). Настройки существующего сервиса и GitHub проверяются отдельно: один YAML не подтверждает их применение. При красной проверке обходить защиту или делать ручной деплой нельзя.

Новые серверные строки содержат безопасный request_id, шаблон маршрута, HTTP-статус и длительность. Они не содержат токены, тела писем и идентификаторы игроков; request_id возвращается в заголовке ответа для диагностики.
