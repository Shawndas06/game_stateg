# Османская кампания

Desktop-стратегия в духе Total War и Suzerain. Кампания: **Беелик → Султанат → Империя**.

---

## Описание

Игра о восхождении Османского государства: от небольшого беелика в Сёгюте до империи с центром в Константинополе. Карта Анатолии и Балкан, крепости эпохи 1299–1453, нарративные события в стиле Suzerain.

---

## Требования

- Python 3.10+
- pygame >= 2.5.0

---

## Установка

```bash
# Клонировать репозиторий
git clone <url-репозитория>
cd "total war"

# Создать виртуальное окружение
python3 -m venv venv

# Активировать (Linux/macOS)
source venv/bin/activate

# Установить зависимости
pip install -r requirements.txt
```

---

## Запуск

```bash
# Активировать venv (если не активирован)
source venv/bin/activate

# Запуск
python3 main.py
```

Или через скрипт:

```bash
./run.sh
```

---

## Геймплей

- **Меню входа** — Новая игра / Выход
- **Карта** — крепости с иконками (зелёные — ваши, красные — Византия)
- **Пошаговый режим** — кнопка «Следующий ход»
- **Нарративные события** — диалоги с выбором в стиле Suzerain
- **Захват крепостей** — механику осады планируется добавить
