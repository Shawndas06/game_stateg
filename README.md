# Османская кампания

**Desktop-стратегия** в духе Total War и Suzerain. Кампания по восхождению Османского государства: **Беелик → Султанат → Империя** (1299–1453).

---

## Описание

Игра о превращении небольшого беелика в Сёгюте в империю с центром в Константинополе. Карта Анатолии и Балкан с исторически размещёнными крепостями. Пошаговый режим, осады, дипломатия, законы, строительство, нарративные события.

---

## Геймплей

### Меню
- **Новая игра** — начать кампанию
- **Загрузить** — продолжить сохранение
- **Настройки** — оконный/полноэкранный режим
- **Выход**

### Карта
- **Клик по крепости** — открыть диалог (своя / вражеская)
- **Колёсико мыши** — зум карты
- **ЛКМ + перетаскивание** — панорама

### Своя крепость
- **Наём войск** — ополченцы, конница, лучники (Бейлик); азапы, сипахи, янычары (Султанат); и др.
- **Строить** — стены, мечеть, рынок, казармы, катапульты, медресе
- **Наместник** — назначить правителя
- **Столица** — перенести столицу (если не столица)
- **Имя** — переименовать крепость
- **Полководец** — выбрать командующего полевой армией (если армия есть)

### Столица
Дополнительно: **Перевести в армию** — отправить войска из гарнизона в полевую армию.

### Вражеская крепость
- **Осада** — отправить полевую армию (собрана в столице)
- **Штурм** — атаковать сразу (нужно больше войск)
- **Штурм (ослаблены)** — во время осады, после нескольких ходов

### Верхняя панель
- **Ход** — завершить ход (доход, расходы, ходы AI)
- **Дипломатия** — выбор государства → мир, война, дань, союз, НПП, торговля
- **Экономика** — доходы, расходы, итог за ход
- **Законы** — принять законы (эффекты на доход, найм, осаду и т.д.)

### Победа и поражение
- **Победа** — захват Константинополя при 15+ крепостях
- **Поражение** — потеря всех крепостей или смерть султана

## Механики

| Механика | Описание |
|----------|----------|
| Этапы | Бейлик (старт) → Султанат (Бурса) → Империя (Константинополь) |
| Легитимность | 0–100, растёт при захватах, падает при нарушении НПП |
| Здоровье султана | Уменьшается со временем, при 0 — поражение |
| Мятежи | Недовольство в захваченных крепостях (снижается со временем) |
| Зима | Каждый 4‑й ход — доход −15% |
| Сезонность осады | Защитники слабеют при длительной осаде |
| Катапульты | Ускоряют капитуляцию при осаде |

---

## AI

- Строит здания (стены, рынки, казармы)
- Выбирает слабые и близкие цели
- Предлагает торговлю, мир, дань, союз
- Личности фракций: агрессивные, мирные, торговые, оборонительные
- Не атакует при мирных отношениях (peace, nap, alliance)
